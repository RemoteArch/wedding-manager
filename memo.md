1. Flow organisateur
1. Créer l’événement

L’organisateur peut :

créer un événement

définir le nom, le type et la description

définir la date de début, la date de fin, la date/heure de cérémonie

définir le lieu principal

ajouter plusieurs moments si besoin : cérémonie, réception, after, etc.

publier ou laisser l’événement en brouillon

Fonctionnalités souvent oubliées ici

modifier l’événement après création

dupliquer un événement existant

annuler ou reporter l’événement

archiver l’événement après la fin

2. Configurer l’expérience de l’événement

L’organisateur peut :

personnaliser le site de l’événement

définir le message avant l’événement

définir le message pendant l’événement

définir le message après l’événement

configurer le countdown

définir les informations pratiques : adresse, itinéraire, dress code, consignes

Oublis fréquents

page programme / agenda

FAQ invités

contact organisateur

message différent selon statut de l’invité

3. Ajouter et organiser les invités

L’organisateur peut :

créer un invité manuellement

importer une liste d’invités

définir téléphone, email, famille, groupe, catégorie

associer accompagnants ou membres d’une famille

classer les invités par tags : VIP, famille, amis, collègues, staff

Oublis fréquents

gérer les doublons

rechercher rapidement un invité

filtrer les invités par groupe/statut

modifier un invité après création

supprimer ou désactiver une invitation

gérer les accompagnants

4. Gérer les réponses des invités

L’organisateur peut :

voir qui a reçu son invitation

voir qui a confirmé

voir qui a refusé

voir qui n’a pas encore répondu

relancer les personnes sans réponse

Oublis fréquents

RSVP confirmé / refusé / en attente

date de réponse

nombre de personnes confirmées par invitation

blocage des réponses après une date limite

5. Préparer le plan de salle

L’organisateur peut :

définir l’espace

définir les zones où on peut placer des tables

définir les zones bloquées

ajouter les tables

choisir leur forme

définir leur capacité

ajouter les chaises autour des tables

voir une disposition 2D

Oublis fréquents

déplacer les tables facilement

verrouiller certaines tables

gérer plusieurs salles ou zones

ajouter des éléments fixes : scène, buffet, piste, sortie

vérifier automatiquement si une table dépasse la capacité

6. Placer les invités

L’organisateur peut :

assigner un invité à une table

assigner un invité à une chaise précise

voir les places vides

déplacer un invité d’une place à une autre

voir la liste invités + table + chaise

Oublis fréquents

placer des groupes ensemble

empêcher certains placements incompatibles

marquer des invités “sans table encore”

impression ou export du plan de salle

aperçu rapide par table

7. Envoyer les invitations et rappels

L’organisateur peut :

envoyer une invitation par téléphone

envoyer un lien personnel

envoyer un code ou QR code

envoyer un rappel avant l’événement

envoyer un message de bienvenue le jour J

envoyer un message après l’événement

Oublis fréquents

historique des envois

savoir si le message a été reçu / ouvert

renvoyer une invitation

personnaliser le contenu par groupe d’invités

8. Gérer l’entrée et la présence

L’organisateur ou les hôtesses peuvent :

rechercher un invité

scanner son code

marquer sa présence manuellement

voir s’il est déjà entré

voir l’heure d’arrivée

savoir qui l’a enregistré

Oublis fréquents

empêcher le double scan

accepter l’entrée d’un accompagnant

marquer un invité absent

corriger une erreur de check-in

dashboard live des présents / absents

check-in par point d’entrée

9. Suivre l’événement en direct

L’organisateur peut :

voir combien d’invités sont arrivés

voir quelles tables sont complètes

voir les commentaires reçus

voir les photos et vidéos envoyées

modérer les contenus

Oublis fréquents

validation avant affichage public

suppression d’un contenu inapproprié

mise en avant de certains messages ou médias

10. Clôturer l’événement

L’organisateur peut :

voir le résumé final

exporter la liste des présences

exporter la liste des invités

récupérer les photos/vidéos

afficher le message post-événement

Oublis fréquents

statistiques finales

archivage

désactivation des scans après l’événement

fermeture des uploads après une certaine date

2. Flow invité
1. Recevoir son invitation

L’invité peut :

recevoir un message d’invitation

ouvrir son lien personnel

voir les détails de l’événement

voir son code ou QR code d’entrée

Oublis fréquents

vérifier que le lien est déjà utilisé ou non

afficher un message si l’invitation n’est plus valide

afficher un message si l’événement est terminé

2. Répondre à l’invitation

L’invité peut :

confirmer sa présence

refuser

indiquer le nombre de personnes

laisser un message à l’organisateur

Oublis fréquents

modifier sa réponse avant la date limite

préciser ses besoins particuliers

ajouter accompagnant si autorisé

3. Consulter les infos utiles

L’invité peut :

voir la date et l’heure

voir le lieu

voir l’itinéraire

voir le programme

voir le countdown avant l’événement

Oublis fréquents

message spécial quand l’événement est en cours

message simple après l’événement

rappel des consignes importantes

4. Accéder à l’événement

L’invité peut :

présenter son QR code

se faire scanner à l’entrée

être marqué présent manuellement si besoin

Oublis fréquents

message “vous avez déjà été enregistré”

message de bienvenue après scan réussi

gestion d’un scan refusé ou invalide

5. Se repérer dans la salle

L’invité peut :

voir sa table

voir éventuellement son siège

retrouver son emplacement

Oublis fréquents

vue simple “ma table”

aide rapide par nom ou code

indication de zone/salle

6. Participer pendant l’événement

L’invité peut :

envoyer des vœux

laisser un commentaire

envoyer des photos

envoyer des vidéos

consulter la galerie

Oublis fréquents

voir si son contenu est en attente de validation

modifier ou supprimer son propre message

savoir si les uploads sont encore ouverts

7. Après l’événement

L’invité peut :

voir un message de remerciement

consulter la galerie finale

laisser un dernier message si c’est encore ouvert

Oublis fréquents

fermeture automatique des interactions après une date

page souvenir simple après l’événement

3. Flow hôtesse / staff accueil

L’hôtesse peut :

se connecter à l’espace accueil

rechercher un invité par nom, téléphone ou code

scanner un QR code

marquer une présence manuellement

voir si l’invité est déjà entré

voir à quelle table l’invité est placé

orienter l’invité vers sa table

Oublis fréquents

droits limités pour le staff

historique des actions par hôtesse

correction d’une erreur de scan

filtrer les invités déjà arrivés / pas encore arrivés

4. Flow admin plateforme

Si c’est un vrai SaaS, il y a aussi ce flow.

L’admin plateforme peut :

gérer les organisateurs

gérer plusieurs événements

activer / désactiver un compte

voir l’usage de la plateforme

gérer les quotas

voir les incidents ou abus

Oublis fréquents

gestion des abonnements

gestion du stockage

modération globale si besoin

support client

5. Les oublis les plus importants en format “flow”

Si on résume en pur besoin fonctionnel, tu as surtout oublié ces passages de parcours :

Avant l’événement

confirmer ou refuser l’invitation

relancer les invités sans réponse

consulter programme / lieu / consignes

gérer accompagnants et groupes

Pendant l’événement

retrouver sa table facilement

gérer les scans refusés, doubles ou invalides

modérer photos, vidéos et commentaires

suivre le nombre réel de présents en direct

Après l’événement

fermer les scans

fermer ou limiter les uploads

remercier les invités

archiver ou exporter les données

6. Version ultra synthétique du flow global
Le flow global cohérent devient plutôt :

Organisateur
Créer événement → configurer règles de l’événement → configurer site/publication → ajouter invités → définir règles d’invitation/RSVP → envoyer invitations → suivre réponses → préparer espace/salles → générer plan de salle → placer invités → ouvrir check-in → suivre événement en direct → clôturer événement → archiver

Invité
Recevoir invitation → ouvrir page d’invitation → consulter infos → répondre RSVP → recevoir confirmation / rappel → se présenter à l’événement → être check-in → retrouver sa table → participer à l’événement → consulter page post-événement

Hôtesse / staff
Accéder à l’espace accueil → rechercher/scanner invité → vérifier validité → marquer présence → consulter placement → orienter invité → gérer exceptions d’accès
